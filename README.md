# Hanzi Spirit

Hanzi Spirit is a multimodal platform that explores the etymology of Chinese characters and generates artistic visual representations using Google's Gemini AI.

## Features

- **Etymology Analysis**: Deep semantic analysis of Chinese characters using Gemini 3.1 Pro.
- **Multimodal Art Generation**: Real-time generation of atmospheric images using Gemini 3.1 Flash Image.
- **Dynamic Atmosphere**: Interactive visual experience.

## Reproducible Testing Instructions

Follow these steps to set up and run the project locally.

### Prerequisites

- **Node.js**: Ensure you have Node.js (v18+) installed.
- **Google Cloud Platform (GCP) Account**:
  - A project with **Cloud Run** and **Cloud Storage** enabled.
  - An API Key for **Gemini API** (with access to Gemini 3.1 models).
  - Service account credentials for Cloud Storage access.

### Setup

1. **Clone the repository**:
   ```bash
   git clone <your-repo-url>
   cd hanzi-spirit
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Configure Environment Variables**:
   Copy the `.env.example` file to `.env` and fill in the required values:
   ```bash
   cp .env.example .env
   ```
   *Required variables in `.env`:*
   - `GEMINI_API_KEY`: Your Gemini API Key.
   - `GOOGLE_APPLICATION_CREDENTIALS`: Path to your GCP service account JSON key file.

4. **Start the development server**:
   ```bash
   npm run dev
   ```

5. **Verify**:
   - Open your browser and navigate to `http://localhost:3000`.
   - Enter a Chinese character (e.g., "山") in the search bar.
   - You should see the character's etymology and an atmospheric image generated by Gemini.

## Deployment

This project is designed to be deployed on Google Cloud Run. Ensure your `Dockerfile` is configured correctly and use the `gcloud` CLI to deploy:

```bash
gcloud run deploy
```
